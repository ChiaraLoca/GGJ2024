# Dillo

## Descrizione Italiano

Dillo è un gioco cooperativo per due giocatori in cui un giocatore scrive parole e l'altro deve pronunciarle al momento giusto per superare gli ostacoli.
Questo gioco con microfono e tastiera lascia l'idiozia nelle mani di chi scrive e di chi grida.

## English Description

Dillo (Say it)is a two-player cooperative game in which one player writes words and the other must say them at the right time to overcome obstacles.
This game with a microphone and keyboard control scheme leaves the idiocy in the hands of the writer and the shouter.
